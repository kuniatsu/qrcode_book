# QRコードブックマーク

QRコードをスキャンして保存・管理するWebアプリケーションです。位置情報や登録日時と共にQRコードを保存し、後から参照できます。

## 機能

- **QRコードスキャン**: デバイスのカメラを使ってQRコードを読み取り
- **位置情報の記録**: スキャン時の位置情報（緯度・経度）を自動保存
- **データ管理**: LocalStorageを使用したデータの永続化
- **詳細表示**: QRコードの内容、登録日時、位置情報を一覧表示
- **メモ機能**: 各QRコードにメモを追加可能
- **データのエクスポート/インポート**: JSON形式でのバックアップと復元
- **レスポンシブデザイン**: スマートフォン・タブレット・デスクトップに対応

## 技術スタック

- **HTML5**: セマンティックマークアップ
- **CSS3**: レスポンシブデザイン、Flexbox/Grid
- **JavaScript (ES6+)**: Vanilla JavaScript（フレームワークなし）
- **jsQR**: QRコード読み取りライブラリ
- **qrcode.js**: QRコード生成ライブラリ
- **LocalStorage**: データの永続化

## セットアップ

このアプリは完全に静的なWebアプリケーションなので、特別なビルドプロセスやサーバーサイドの設定は不要です。

### ローカルで実行する場合

1. リポジトリをクローン:
```bash
git clone <repository-url>
cd qrcode_book
```

2. HTTPサーバーを起動:
```bash
# Python 3の場合
python -m http.server 8000

# Node.jsのhttp-serverを使用する場合
npx http-server -p 8000
```

3. ブラウザで `http://localhost:8000` にアクセス

### ホスティングする場合

以下のホスティングサービスで簡単にデプロイできます:

- **GitHub Pages**: リポジトリの設定からGitHub Pagesを有効化
- **Netlify**: リポジトリを接続してデプロイ
- **Vercel**: リポジトリを接続してデプロイ
- **Firebase Hosting**: `firebase deploy`でデプロイ

## 使い方

### QRコードをスキャンする

1. 下部ナビゲーションの「カメラ」ボタンをタップ
2. カメラへのアクセスを許可
3. QRコードをカメラに向ける
4. 自動的に読み取られたら「保存する」ボタンをタップ

### QRコードを確認する

1. ホーム画面で保存したQRコードの一覧を表示
2. QRコードをタップして詳細を表示
3. 内容のコピー、URLを開く、メモの追加などが可能

### データをバックアップする

1. 設定画面を開く
2. 「データをエクスポート」ボタンをタップ
3. JSONファイルがダウンロードされます

### データを復元する

1. 設定画面を開く
2. 「データをインポート」ボタンをタップ
3. 以前エクスポートしたJSONファイルを選択

## ブラウザの対応状況

以下のAPIを使用しているため、モダンブラウザが必要です:

- getUserMedia API（カメラアクセス）
- Geolocation API（位置情報取得）
- LocalStorage API（データ保存）
- Canvas API（QRコード読み取り）

### 推奨ブラウザ

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

### 注意事項

- HTTPSまたはlocalhostでのみカメラと位置情報が利用可能です
- iOSのSafariでは全画面表示が推奨されます

## プライバシー

- すべてのデータはブラウザのLocalStorageに保存されます
- データはインターネットに送信されません
- 位置情報はユーザーの許可がある場合のみ取得されます
- 設定画面から位置情報の取得を無効化できます
